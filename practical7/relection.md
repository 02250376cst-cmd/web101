# Reflection – Practical 7: Data Visualization

Working on this practical gave me a deeper understanding of how **data visualization** can transform raw data into meaningful insights. Here are my key takeaways:

##  What I Learned
- How to set up and use **Recharts** and **react-chartjs-2** in a React project.
- The importance of **responsive design** in dashboards, ensuring charts adapt to different screen sizes.
- How to **map and transform data** (e.g., formatting dates with `date-fns`) before feeding it into charts.
- The difference between chart types:
  - Line charts for trends (sales over months).
  - Pie charts for distribution (product categories).
  - Bar charts for comparison (customer acquisition).
  - Area charts for continuous data (weekly visitors).

##  Challenges Faced
- Understanding the configuration options for Chart.js, especially stacked bars and tooltips.
- Debugging small syntax errors in JSX (like misplaced brackets or typos in props).
- Ensuring charts were **interactive and visually clear** without clutter.

##  Skills Improved
- React component structuring and modularization.
- Practical use of external libraries in real-world projects.
- Thinking about **data presentation** from a user’s perspective.

##  Overall Reflection
This practical was not just about coding charts—it was about learning how to **tell a story with data**. I realized that visualization is a powerful tool in analytics, helping businesses and users make informed decisions quickly. Building this dashboard felt like creating a bridge between raw numbers and actionable insights.
