# Reflection: Todo List Application with Zustand

Working on this practical gave me a clear understanding of how state management can be simplified using Zustand. At first, I was used to passing props down or using Context, but I realized how messy that gets when components grow. Zustand felt lightweight and easy to set up.

I liked how components only subscribe to the state they need, which made the app more efficient. Writing actions like `addTodo`, `toggleTodo`, and `removeTodo` was straightforward, and adding persistence with localStorage made the app feel more complete. It was satisfying to see my todos stay even after refreshing the page.

One challenge I faced was setting up the project correctly with Vite and making sure file names matched imports. Fixing those errors taught me to pay attention to details like extensions and folder paths. Once everything was aligned, the app ran smoothly.

Overall, this practical helped me connect theory with actual implementation. I now feel more confident about using Zustand in future projects, and I appreciate how much cleaner the code looks compared to other state management approaches.
